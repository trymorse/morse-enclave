# Contributing

Morse exports this repository from its private monorepo on each release, so a change made here would be overwritten by the next export.

- Issues are welcome. Open one to report a bug, ask a question, or point out a build that does not reproduce. Say which tag you looked at.
- Pull requests are not merged. If you have a fix, describe it in an issue, and Morse makes the change in the monorepo so it ships with the next release.
- Report a security problem privately, as `SECURITY.md` says. Do not open a public issue for it.
